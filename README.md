# Мухавец — история рядом

Статический путеводитель по трём местам Мухавца: школьный музей (`school-museum.html`), памятник Сергею Ефимовичу Богданчуку (`monument.html`) и памятник «Землякам, погибшим в годы Великой Отечественной войны» (`memorial.html`).

Новый интерфейс использует светлые полупрозрачные панели, адаптированные для телефона и компьютера. На `monument.html` по умолчанию открывается прогулка у памятника: WASD/стрелки и обзор мышью на ПК, джойстик и обзор пальцем на телефоне. Можно подойти к памятнику, обойти его, прочитать доску и открыть настоящую информационную табличку. Дополнительный режим «Общий вид» позволяет вращать общий вид. Доступны пять исходных фотографий и видео обхода.

Модель памятника — ручная приближённая реконструкция по съёмке пользователя, а не точный фотограмметрический скан. Постамент, ступени и боковой блок восстановлены по силуэтам; бюст содержит приблизительную геометрию и проекции подлинных фотографий. Обмеров нет. Надпись и даты приведены по оригинальной мемориальной доске. Модель GLB занимает около 9,8 МБ; технические сведения находятся в `assets/monument/model-info.json`.

## Музей

- Телефон: сенсорный джойстик и обзор пальцем; в общем виде масштаб двумя пальцами.
- ПК: WASD/стрелки и обзор мышью.
- Размеры помещения оценены по фотографиям и видео, точных обмеров нет.
- По запросу пользователя длина и ширина модели увеличены на 20%: план 6,96 × 7,80 м, высота 2,85 м. Мебель и экспонаты не масштабировались вместе с комнатой; бытовой уголок отдельно расширен по общим видам.
- Границы движения вычисляются из геометрии мебели. Проверены пересечения отдельных деталей разных экспозиций и доступность всех 11 точек осмотра.
- Исторические фотографии и изображения стендов предоставлены пользователем.
- Фактуры сосны, старого дерева и плетения созданы инструментом imagegen.
- Three.js 0.160.1 используется по лицензии MIT.

Все необходимые скрипты и изображения находятся в корне репозитория. Изображения галереи загружаются при открытии; печатные стенды повышают разрешение при приближении.

Изменения экспонатов и света (v5):

- Угольные утюги: полый корпус, продухи, крышка, шарнир, защёлка и деревянная рукоять; отдельный литой утюг.
- Семь напольных керосиновых фонарей: бачок, пробка, горелка с фитилём, стеклянная колба, проволочная защита, вентиляция и откидная ручка. Один фонарь без стекла, как в кадре видео. Настольная лампа с зелёной ножкой.
- Формы сопоставлены с предоставленным видео IMG_5581 (98–99 с). Детали разных материалов объединяются для сокращения количества отрисовок; мобильная версия использует менее плотную геометрию.
- Нейтральный отражённый свет, мягкие направленные тени и локальные контактные тени под экспонатами. Изображения исторических стендов сохраняют исходные цвета.
- Проверены клавиатура, сенсорный джойстик и галерея в браузере на экранах 1440×960, 390×844, 844×390 и 320×568. Эмуляция не заменяет проверку на физическом телефоне.

Фактура `assets/cast-iron-v5.png` сгенерирована встроенным инструментом imagegen из описания спокойной бесшовной поверхности окисленного чугуна с мелкими порами, без направленного рисунка и запечённых теней. Исторические изображения и подписи не генерировались.


## Публикация на GitHub Pages

В Settings → Pages выбран источник Deploy from a branch: ветка `main`, папка `/ (root)`. При отправке изменений в `main` GitHub обновляет сайт автоматически.

Все ссылки на файлы относительные, поэтому сайт работает в подпапке GitHub Pages. Серверная часть и база данных не требуются.

Для локального просмотра: `python3 tools/serve-preview.py` из корня репозитория, затем откройте http://127.0.0.1:64467/. Сервер поддерживает перемотку видео через HTTP Range.

Исторические изображения предоставлены для этого музейного проекта. Лицензия Three.js находится в LICENSE-three.txt.

Проверены маршруты вокруг памятника, клавиатура, джойстик при ширине 390 px и открытие оригинальных табличек. Публичный сайт: https://z7bv4pbtvp-star.github.io/mukhavets-school-museum/.

## Помощь посетителю — 21.10.2026

Инструкция по эксплуатации: [guide.html](guide.html). Она описывает управление на компьютере и телефоне, условия зачёта заданий, работу с видео, сохранение и скачивание дневника, сценарий урока и решение типичных затруднений. В каждой прогулке кнопка `?` открывает краткую помощь и настройку качества. Экономный режим уменьшает разрешение рендера, отключает тени и размытие интерфейса; фотографии и видеоролики не перекодируются.

Добавлены резервное сохранение в sessionStorage при недоступном localStorage и скачивание дневника в HTML для печати (Markdown также доступен). Исправлены зачёт таблички при обратном листании, фокус полей при обновлении из другой вкладки и невидимые метки в клавиатурной навигации. После прохождения трёх этапов можно перейти к оформлению общего вывода.

## Оформление и прогулки — 22.10.2026

Главная использует подлинную фотографию экспозиции, пару Manrope / Cormorant Garamond, светлый бумажный фон и прозрачную шапку. Места представлены крупными фотографиями с отдельными описаниями; счётчик маршрута отражает реальные завершённые этапы. Шрифты включены локально, лицензии — в `heritage-fonts-LICENSE.txt`. Краткая инструкция открывается на месте, полная доступна в `guide.html`.

Панель маршрута можно свернуть. Исправлены сенсорные зоны памятников, обрезание нижней панели на 320 px и открытие выбранной таблички Богданчука. Проверены джойстик с фактическим перемещением камеры, поворот телефона (844 × 390), полный путь из семи точек с итогом 3/3, видео и отсутствие ошибок в консоли. Физический телефон остаётся отдельным уровнем проверки. Понижение качества во время движения и скрытия вкладки не запускает лишних изменений framebuffer.

Скульптура большого памятника использует `sculpture-v14.glb`: замкнутый объём фигур, отдельные головы, каска, руки, оружие, складки и знамя. Проекция подлинного видео ограничена передней поверхностью камня; фон и растительность исключены. Профиль и оборотная сторона имеют самостоятельную геометрию. Проверены три ракурса и отсутствие открытых границ у основного объёма. Это ручная приближённая реконструкция, без обмеров и без статуса фотограмметрического скана. Технические сведения — в `assets/memorial/model-info.json`.
