# Школьный музей Мухавца

Статический сайт с прогулкой по 3D-модели и галереей исходных фотографий.

- Телефон: сенсорный джойстик и обзор пальцем; в общем виде масштаб двумя пальцами.
- ПК: WASD/стрелки и обзор мышью.
- Размеры помещения оценены по фотографиям и видео, точных обмеров нет.
- По запросу пользователя длина и ширина модели увеличены на 20%: план 6,96 × 7,80 м, высота 2,85 м. Мебель и экспонаты не масштабировались вместе с комнатой; бытовой уголок отдельно расширен по общим видам.
- Границы движения вычисляются из геометрии мебели. Проверены пересечения отдельных деталей разных экспозиций и доступность всех 11 точек осмотра.
- Исторические фотографии и изображения стендов предоставлены пользователем.
- Фактуры сосны, старого дерева и плетения созданы инструментом imagegen.
- Three.js 0.160.1 используется по лицензии MIT.

Все необходимые скрипты и изображения находятся в корне репозитория. Изображения галереи загружаются при открытии; печатные стенды повышают разрешение при приближении.

Изменения экспонатов и света (v5):

- Угольные утюги: полый корпус, продухи, крышка, шарнир, защёлка и деревянная рукоять; отдельный литой утюг.
- Семь напольных керосиновых фонарей: бачок, пробка, горелка с фитилём, стеклянная колба, проволочная защита, вентиляция и откидная ручка. Один фонарь без стекла, как в кадре видео. Настольная лампа с зелёной ножкой.
- Формы сопоставлены с предоставленным видео IMG_5581 (98–99 с). Детали разных материалов объединяются для сокращения количества отрисовок; мобильная версия использует менее плотную геометрию.
- Нейтральный отражённый свет, мягкие направленные тени и локальные контактные тени под экспонатами. Изображения исторических стендов сохраняют исходные цвета.
- Проверены клавиатура, сенсорный джойстик и галерея в браузере на экранах 1440×960, 390×844, 844×390 и 320×568. Эмуляция не заменяет проверку на физическом телефоне.

Фактура `assets/cast-iron-v5.png` сгенерирована встроенным инструментом imagegen из описания спокойной бесшовной поверхности окисленного чугуна с мелкими порами, без направленного рисунка и запечённых теней. Исторические изображения и подписи не генерировались.


## Публикация на GitHub Pages

В Settings → Pages выбран источник Deploy from a branch: ветка `main`, папка `/ (root)`. При отправке изменений в `main` GitHub обновляет сайт автоматически.

Все ссылки на файлы относительные, поэтому сайт работает в подпапке GitHub Pages. Серверная часть и база данных не требуются.

Для локального просмотра: `python3 -m http.server 8000` из корня репозитория, затем откройте http://localhost:8000/.

Исторические изображения предоставлены для этого музейного проекта. Лицензия Three.js находится в LICENSE-three.txt.
