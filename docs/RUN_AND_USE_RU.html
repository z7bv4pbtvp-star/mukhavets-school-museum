1. Вход на сайт

Публичный адрес проекта: z7bv4pbtvp-star.github.io/mukhavets-school-museum/.

На главном экране сразу доступны три прогулки. Нажмите на фотографию или название места, чтобы свободно его осмотреть. Кнопка «Начать с музея» запускает последовательный маршрут; при сохранённом прохождении она меняется на «Продолжить маршрут».

Публичный сайт работает с хостинга GitHub Pages и не требует включённого Mac. Адрес 127.0.0.1:64467 предназначен только для локального просмотра на том компьютере, где запущен сервер.

Управление на компьютере

  • W, A, S, D или стрелки — движение.
  • Удерживайте кнопку мыши и потяните сцену — поворот взгляда.
  • Кнопки объектов внизу экрана помогают подойти к стенду, памятнику, стене памяти, датам или табличке.
  • «Общий вид» / «Вся модель» — вращение мышью; колёсико и кнопки + / − меняют масштаб. Для ходьбы выберите «Прогулка».
  • Esc закрывает открытое окно. Tab выбирает кнопку, Enter активирует её.

Управление на телефоне

  • Ведите джойстик слева для движения.
  • Другим пальцем проводите по свободной части сцены для поворота взгляда.
  • В общем виде два пальца меняют масштаб, один палец вращает сцену.
  • Панель маршрута можно свернуть, чтобы лучше видеть экспонаты. Кнопка ? открывает помощь и настройку качества.

Как пройти маршрут

  1. Школьный музей: рассмотрите фотографии стенда «Помним» и предметов быта.
  2. Памятник Сергею Богданчуку: откройте мемориальную доску и информационную табличку.
  3. Памятник землякам: рассмотрите стену памяти, доску на памятнике и табличку у площади.

Кнопка «К точке» перемещает к объекту. Чтобы получить отметку о выполнении, откройте его фотографию. Все задания и галочки доступны в панели «Мой маршрут». Между локациями используется переход по кнопке; непрерывного пути по улицам здесь нет.

День и ночь у памятников

Переключатель «День / Ночь» под названием места меняет небо, освещение и цвета интерфейса. Ночью включаются фонари по периметру и направленная подсветка скульптуры. Ракурс сохраняется. Выбор запоминается для обоих памятников в этом браузере; музей сохраняет своё внутреннее освещение.

Архитектурная подсветка — художественное дополнение виртуальной прогулки. Она не подтверждает наличие таких фонарей на реальном месте.

Видео, фотографии и дневник

«Видео» открывает рассказ о выбранном месте. Если браузер не начал воспроизведение, нажмите ▶ «Воспроизвести». Доступны перемотка на 10 секунд и изменение скорости. При закрытии окна ролик останавливается.

«Фотографии» / «Надпись» открывают оригинальные снимки. Стрелки переключают фотографии. Они позволяют сверить детали с 3D-реконструкцией и прочитать надписи.

«Дневник исследователя» хранит наблюдения в этом браузере. Укажите деталь, источник и свой вывод. Готовый дневник можно скачать как HTML для печати или Markdown для редактирования.

Прогресс и записи не синхронизируются между телефоном и компьютером и не отправляются учителю автоматически. Скачайте дневник перед очисткой данных браузера.

2. Как запустить код из архива

  1. Распакуйте ZIP. Внутри находится папка mukhavets-site с кодом, моделями, фотографиями и видео.
  2. Для локального сервера нужен Python 3. Проверьте его в терминале командой python3 --version, в Windows — py -3 --version. Если Python отсутствует, установите его с python.org.
  3. Откройте терминал в папке mukhavets-site. Запустите одну из команд ниже.

macOS / Linux:

python3 tools/serve-preview.py

Windows:

py -3 tools/serve-preview.py

После запуска откройте в браузере:

http://127.0.0.1:64467/

Оставьте окно терминала открытым. Чтобы остановить локальный сервер, нажмите Ctrl + C в этом окне.

Не открывайте index.html двойным щелчком для запуска прогулок: браузеру нужен HTTP-сервер для модулей, моделей и видеороликов. Это статический сайт — Node.js, сборка, база данных и платный сервер для локального запуска не требуются.

В ZIP включён файл FILES-SHA256.json со списком файлов и контрольными суммами. Он позволяет проверить целостность переданной копии.

Если нужно изменить содержимое

  • Тексты главной страницы меняются в index.html; общие названия мест и задания — в journey-config.js.
  • Видеофайлы находятся в assets/stories/; актуальные адреса заданы в journey-config.js.
  • Расположение объектов площади задаётся в memorial-environment.js. Форма памятника находится в отдельном GLB — редактирование текста HTML её не изменяет.
  • После изменения JS/CSS увеличьте версию в соответствующей ссылке ?v=..., чтобы браузеры загрузили обновление.

4. Как обновить публичный сайт

Репозиторий: z7bv4pbtvp-star/mukhavets-school-museum.

  1. Замените изменённые файлы в тех же папках репозитория и сохраните изменения в ветку main.
  2. В Settings → Pages источник публикации должен быть Deploy from a branch, ветка main, папка / (root).
  3. Дождитесь публикации в разделе Actions → pages build and deployment.
  4. Откройте публичный адрес и проверьте обновлённую главную страницу, все три прогулки и видео.
GitHub Pages не распаковывает загруженный ZIP как сайт: в репозитории должны лежать сами файлы и папки. Публичная копия независима от включённого Mac. При сбоях GitHub публикация может задерживаться; состояние сервиса доступно на githubstatus.com.

5. Если что-то не работает

СитуацияЧто сделать
На телефоне не открывается 127.0.0.1Откройте публичную ссылку GitHub Pages. Локальный адрес указывает на сам телефон, а не на Mac.
Показывается старая версияПроверьте завершение публикации. Обновите страницу с очисткой кэша; при изменениях кода обновляйте параметры версий JS/CSS.
Прогулка тормозитОткройте помощь ?, включите экономное качество. Закройте другие вкладки с 3D. Фотографии остаются доступны отдельно.
Видео не начинает игратьНажмите «Воспроизвести». При ошибке используйте «Повторить» или «Открыть отдельно». Для публичного сайта проверьте соединение с интернетом.
Локальный сервер пишет, что порт занятВозможно, он уже запущен. Откройте адрес 127.0.0.1:64467. Не запускайте несколько копий без необходимости.
Не появляется отметка заданияОткройте нужную фотографию или надпись. Само приближение к объекту не засчитывает просмотр.
После очистки браузера исчезли заметкиДневник хранится локально. Для сохранения используйте скачанный ранее файл; автоматической облачной копии нет.

Исторические фотографии и видеоматериалы предоставлены для проекта. Размеры 3D-реконструкций оценочные. Скульптура памятника землякам восстановлена фотограмметрией по видео; плохо отснятые поверхности могут содержать погрешности. Венок — дополнение виртуальной сцены.

В исходном коде сохранены файлы лицензий сторонних библиотек и шрифтов. Дополнительная инструкция для ученика и учителя: guide.html на публичном сайте.
